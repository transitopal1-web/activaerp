Google Drive — Almacenamiento de Fotos
Para sincronizar fotos con Google Drive necesitas configurar tu Client ID y API Key de Google Cloud Console.
Pasos para obtener credenciales Google
1. Ve a console.cloud.google.com → Nuevo proyecto → Nombre: ActivaERP
2. APIs y servicios → Biblioteca → Activa Google Drive API + Google Picker API
3. Credenciales → + Crear → ID de cliente OAuth 2.0 → Aplicación web
4. Orígenes autorizados: agrega la URL donde abres este archivo (ej. file:// o tu servidor)
5. Crea también una Clave de API → cópiala aquí arriba
6. Pantalla de consentimiento → Scope: https://www.googleapis.com/auth/drive.file
